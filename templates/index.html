PROJECT OVERVIEW

About TruthLens.

A machine-learning project for preliminary fake-news classification.

ⓘ
TL

News screening with machine learning.

TruthLens AI connects a browser dashboard to a locally saved text-classification model. Users submit a headline and article body, the backend transforms the text with the saved vectorizer, and the classifier returns a REAL/FAKE prediction.

The explanation panel displays influential terms when the model supports coefficient-based explanations.

How it works

  1. 01
    Input

    Paste headline and article text.

  2. 02
    Preprocess

    Clean text and apply the saved vectorizer.

  3. 03
    Predict

    Calculate the model's REAL probability.

  4. 04
    Explain

    Show prediction scores and influential terms.

Responsible use

This is a research and educational tool. It does not independently verify facts, identify the original source, or guarantee whether an article is true. Confirm important claims with reputable independent sources.
